FLUXO DE USO SIMPLES
====================

1. Usuário completa trilha 100%

2. useEffect detecta: completionPercentage === 100

3. Chama: useCertificates().issueCertificate(...)

4. Service gera Certificate com:
   - ID único
   - Status "visual"
   - Timestamp

5. Salva em localStorage

6. Retorna Certificate para componente

7. Exibe TrailCompletionCertificate (celebração + confete)

8. Usuário clica "Ver Certificado"

9. CertificatePreview exibe layout institucional

10. Usuário pode:
    - Imprimir (PDF)
    - Baixar (HTML)
    - Fechar


INTEGRAÇÃO COM DJANGO (FUTURO)
===============================

Quando backend estiver pronto:

1. Criar app: python manage.py startapp certificates

2. Copiar modelos de DJANGO_CERTIFICATE_MODELS.md

3. Executar migrations

4. No frontend, descomentar:
   - POST /api/certificates/
   - GET /api/certificates/me/

5. Certificados sincronizam automaticamente

6. Migram de "visual" para "issued"
